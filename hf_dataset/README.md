# Pratyabhijñā World Model — Creative Outputs & Evaluation Dataset

## Dataset Description

This dataset accompanies the paper **"Pratyabhijñā World Model: Creative AI Through
Recognition, Active Inference, and Associative Memory"** (arXiv cs.AI 2026).

The Pratyabhijñā World Model (PWM) is a creative AI system that operationalises
Kashmir Śaiva philosophy through active inference on a DreamerV3-class world model
with frozen LLM augmentation. This dataset contains:

1. **`creative_outputs`**: 13 creative works generated by the full PWM pipeline
   (end-to-end, Phase 6 checkpoint + VimarsaBridgeV2 + nemotron-3-super:120b),
   spanning Sanskrit, Kannada, English, and mixed-script poetry across classical
   and contemporary styles.

2. **`hypothesis_results`**: Phase-gated evaluation results for all 9 pre-registered
   hypotheses (H1–H9) and 6 ablations (A1–A6).

## Dataset Creation

### Creative Outputs

Each creative work was generated using the complete PWM pipeline:

1. **World Model warmup**: `TrikaWorldModel` (3-level RSSM, Phase 6, seed 55) runs
   `warmup_steps` observe-step iterations on random stimulus, building a vimarśa
   state `h_t` representing the creative disposition.
2. **VimarsaBridgeV2**: The WM state is projected to LLM token-space, producing a
   logits-processor that biases the 120B model toward creative, aesthetically rich
   output.
3. **WMReasoningTrace (ADR-002)**: `h_t` is serialised as a structured
   `<think>…</think>` assistant-role prefill, providing the LLM with a pre-computed
   "reasoning" state derived from the WM's vimarśa.
4. **Generation**: `nemotron-3-super:120b` via Ollama generates the creative text
   conditioned on the WM state.
5. **Scoring**: Each output is scored with the camatkāra heuristic
   (R_camatk = α₁ΔF + α₂ΔI_Hopfield + α₃Empowerment) and structural metrics.

### Hypothesis Results

Results are extracted from `benchmarks/results/phase_*_gate.json` files and
represent the authoritative phase-gate evaluation for each hypothesis.

## Dataset Fields

### creative_outputs split

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Output identifier (s01–s13) |
| `title` | string | Descriptive title including style/tradition |
| `language` | string | Primary language (Sanskrit, Kannada, English, mixed) |
| `style` | string | Poetic tradition and form description |
| `text` | string | The generated creative work |
| `wm_seed` | int | Random seed for WM warmup |
| `warmup_steps` | int | Number of WM observe-step iterations |
| `wm_vfe` | float | Variational free energy at generation time |
| `wm_prefix` | string | Human-readable WM state description injected |
| `camatk_total` | float | Total camatkāra score [0–1] |
| `r_camatk` | float | Camatkāra reward component |
| `vfe_score` | float | VFE-derived quality component |
| `generated_at` | string | ISO 8601 generation timestamp |
| `model` | string | LLM backend model name |
| `checkpoint` | string | WM checkpoint identifier |

## Ethical Statement

All creative outputs are machine-generated. The Sanskrit and Kannada texts were
generated by an LLM (nemotron-3-super:120b) conditioned on a world model trained
on public domain texts (GRETIL, Project Gutenberg, Poetry Foundation). No private
or copyrighted training data was used. The philosophical framework (Kashmir Śaiva
philosophy) is a 1000-year-old public domain tradition.
